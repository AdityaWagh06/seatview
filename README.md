# SeatView – Movie Seat Booking with 3D Seat Preview

A movie ticket booking page for *Avengers: Doomsday* where you can preview the exact view from any seat in a 3D model of the auditorium before booking.

## Features
- Pick date, showtime and seats (Recliner / Prime / Classic pricing)
- **Preview 3D**: fly into a Three.js auditorium and sit in your chosen seat
- View score for every seat: distance, screen width, head tilt, off-centre angle
- "Show view quality" heatmap on the seat map
- House lights, synthesized theatre sound, look around, zoom, jump to any seat
- **Screen image**: put any image on the theatre screen (or add `screen.jpg` next to `index.html`)

## Run
Open `index.html` in a browser. No build step.
